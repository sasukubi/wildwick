WILDWICK: EVERY NAME IN THE GAME (rename list)
==============================================

HOW TO USE THIS
---------------
1. Find the name you want to change.
2. Write the new name after "new:" on the line underneath it.
     Example:   Cinder Quake
                  new: Ember Slam
3. Leave "new:" empty for anything you're happy with.
4. Save this file and tell Claude "apply the rename list".
   Claude changes the name EVERYWHERE it appears: menus, skill tree text,
   the HUD, banners, controls screen, tips, and so on.

You can also add a note after any line, like:  new: Ember Slam (or Ash Slam?)
Everything shows up in lowercase in the game, so capital letters don't matter.

Names of other things that use a name (for example a skill tree upgrade that
says "Cinder Quake reaches further") update automatically when you rename it.

1. CLASSES (the 6 characters you can play)
============================================================

Warrior
  new:
  what it is: Sword fighter with a shield. Hits harder and takes less damage the lower their flame gets.

Sorcerer
  new:
  what it is: Spellcaster with a staff. Casts fire, frost and wind, and fuses two spells into a stronger one.

Bowman
  new: Archer
  what it is: Archer. Hold to draw the bow longer for a stronger arrow that pierces through enemies.

Rogue
  new:
  what it is: Dagger fighter. Deals double damage when hitting enemies from behind; teleports and uses smoke.

Cleric
  new:
  what it is: Healer with a mace and lantern. Hitting enemies builds Grace, which is spent on heals.

Warlock
  new:
  what it is: Dark caster. Shoots shadow bolts that curse enemies, summons imps, and drains enemies with a beam.
